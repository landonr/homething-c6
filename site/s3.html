homeThing S3

Built on a custom PCB, it adds more buttons and a microphone to the original homeThing.

A faster processor and a larger display.

  • Battery 700mAh
  • Display 170x320 1.9" TFT LCD
  • Wireless Wi-Fi 802.11, BLE 5 + BT mesh
  • Processor ESP32 S3 with an integrated screen, on a Lilygo T-Display S3
  • Memory 16MB Flash, 8MB PSRAM
  • Board Custom PCB for easier setup
  • Controls Scroll wheel, directional pad, 5 buttons
  • I/O Microphone for voice assistant, IR blaster, Stemma QT port
  • Charging USB-C
  • Case 3D printed, 2 parts
